# Niri · Haku Neon

`config.kdl` carga únicamente estos módulos:

- `autostart.kdl`: servicios y aplicaciones de sesión.
- `environment.kdl`: variables Wayland, Qt, Mozilla y Electron.
- `input.kdl`: teclado, touchpad, ratón y gestos.
- `output.kdl`: configuración de `eDP-1`.
- `layout.kdl`: geometría, overview, cursor y capturas.
- `keybinds.kdl`: atajos activos.
- `rules.kdl`: reglas específicas de aplicaciones y capas.
- `effects.kdl`: apariencia global, sombras, opacidad y blur.
- `accent.kdl`: colores dinámicos generados por `set-wallpaper`.

Las configuraciones Haku anteriores y los módulos sin uso están versionados en
`~/backups/haku-shell/`.
