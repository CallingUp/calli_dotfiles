# Scripts

`bin/` contiene los scripts personales de `~/.local/bin` como referencia y respaldo.

`install.sh` instala solo una lista permitida de scripts para QuickShell,
wallpaper, clipboard, controles y lock. El wallpaper/restore portable reemplaza
las rutas antiguas de renderer/SDDM. No instala herramientas de migración,
particionado, importación de chats, limpieza, perfiles de shell ni carga de
claves SSH. Revisa `../docs/INSTALL.md` para dependencias y restauración.
