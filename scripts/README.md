# Scripts

`bin/` contiene los scripts personales de `~/.local/bin` como referencia y respaldo.

`install.sh` restaura los scripts de escritorio, tema, barra, wallpaper, clipboard y Rofi. No restaura automáticamente las herramientas de migración, particionado, importación de chats ni carga de claves SSH: requieren revisión manual porque dependen de rutas, discos o credenciales de esta máquina.
